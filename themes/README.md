# Темы Rex для agterm

Импорт из установленного Rex Beta, без сети, зависимостей и копии ресурсов Rex в Git.
Каждая тема сохраняет 16 ANSI-цветов, фон, текст, курсор и выделение из `source` в sRGB.
Расширенная палитра Rex и Display P3 не переносятся: формат этого экспорта использует sRGB.

Из корня agterm-kit:

```sh
make install-themes
python3 themes/rex.py list
python3 themes/rex.py apply abyssal-trench
python3 themes/rex.py reset
```

Установка добавляет команды `Rex: <название>` и `Rex: вернуть тему agterm` в палитру
пользовательских команд agterm. Они не появляются в штатном Select Theme: этот список
содержит только встроенные темы. Установка сама не меняет выбранные цвета.
Применение меняет цвета всех терминалов agterm и сохраняется после перезапуска.
Пока включена тема Rex, для возврата к встроенной теме сначала выполните reset.

Каталог тем: `~/.config/agterm-kit/rex/`. Команды: управляемый блок `rex` в
`~/.config/agterm/keymap.conf`. Применённые цвета: такой же блок в `ghostty.conf`.
`XDG_CONFIG_HOME` меняет корень; личные пути формируются только при установке.
Чужие строки остаются, симлинки и права сохраняются, перед изменением создаётся `.bak.*`.
Повреждённые маркеры останавливают запись. Другую сборку Rex можно указать через
`--source /путь/к/themes.json`; вход проверяется полностью до записи.
`--no-reload` записывает файлы без подключения к agterm.

Проверки: `python3 -m unittest discover -s themes/tests -v` (также входит в `make test`).
Полный eval установленного каталога: `make eval-themes`. Он проверяет цвета каждой темы
через CLI и конечный `ghostty.conf`, затем reset; порог 100%, отчёт в `/tmp/rex-eval-*/report.json`.

Ограничение записи: файлы заменяются по одному атомарно, вся установка не является
транзакцией. При нехватке места или отказе доступа после части записей устраните причину
и повторите установку. Повторный запуск безопасен, прежние версии сохранены в `.bak.*`.
