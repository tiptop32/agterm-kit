# agterm-kit

Обвязка для терминала agterm: shell-функции и скрипты поверх `agtermctl`. Описание в `README.md`.

## Команды

- `make test`: bats-тесты, без сети и без настоящего agterm.
- `make lint`: `zsh -n` и shellcheck.
- Pre-commit (`make hooks`) гоняет оба.

## Правила

- Одна утилита, один каталог (`wt/`), свои тесты в `tests/`, свой раздел в `README.md`.
- Личные пути в код не попадают: они живут в конфиге пользователя
  (`~/.config/agterm-kit/*.conf`), в репозитории лежит только `*.conf.example`.
- Конфиг читается как данные, а не исполняется: никакого `source` и `eval` над ним.
- Имена тестов bats пишутся ASCII: bats побайтно кодирует имена и ломается на кириллице.
  Комментарии и сообщения на русском.
- Тесты вызывают функции через `zsh -f -c` с изолированным `HOME` и поддельным `agtermctl`
  из `tests/helpers.bash`. Новый тест поведения должен падать на коде без изменения.
